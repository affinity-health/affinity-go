# Contributing

The Go code is generated by Fern from `spec/affinity.openapi.json`. Do not edit generated files;
see [AGENTS.md](AGENTS.md) for which files are hand-written.

## Regenerate

You need Docker, Node (for `npx`) and jq. No Fern account is used.

```sh
scripts/generate.sh
```

It adds Fern's method names and pagination to a copy of the contract
(`scripts/prepare-spec.jq`), runs the pinned Fern CLI and Go generator in Docker, replaces the
generated files, moves Fern's reference to `docs/reference.md` and writes `generation.json`.
Running it twice gives the same tree.

## Verify

```sh
scripts/generate-check.sh
docker run --rm -v "$PWD":/src -w /src golang:1.23 \
  sh -c 'go build ./... && go vet ./... && go test $(go list ./... | grep -v "_test$")'
```

To call a real API, put `AFFINITY_API_KEY` (a Test key), `AFFINITY_BASE_URL` and optionally
`AFFINITY_SMOKE_WEBHOOK_URL` in an env file outside the repository and run:

```sh
docker run --rm --env-file /path/to/smoke.env -v "$PWD":/src -w /src golang:1.23 go run ./tests/smoke
```

Never commit an env file or an API key.
