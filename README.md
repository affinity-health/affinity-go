# Affinity Go SDK

Server-side client for the Affinity API, version `2026-09-28`. Requires Go 1.21+.
This is an initial preview distributed through GitHub. Package-registry publication is deferred.
Pin a commit when using this preview in an application.

## Install

```sh
go get github.com/affinity-health/affinity-go@main
```

## Use

Set `AFFINITY_API_KEY` to a Test key in your server environment. Never put API keys in browser or mobile code.

```go
import (
    "context"
    "os"
    affinity "github.com/affinity-health/affinity-go"
    "github.com/affinity-health/affinity-go/client"
    "github.com/affinity-health/affinity-go/option"
)

api := client.NewClient(
    option.WithAPIKey(os.Getenv("AFFINITY_API_KEY")),
    option.WithAffinityVersion(affinity.String("2026-09-28")),
    option.WithMaxAttempts(1),
)
orders, err := api.Orders.ListOrders(context.Background(), &affinity.ListOrdersRequest{})
```

Handle `err` before using `orders`. Supply a context with a deadline for application requests.

See [the API reference](reference.md) for resource methods and request options. The client defaults to the production API host; a Test key selects Test mode. Use a stable idempotency key for each logical write and reuse it on retry. List responses expose `hasMore`; pass the last resource ID as `startingAfter` to request another page.

## Verify

```sh
go build ./...
go test ./smoke
```

Tests use local mock transports. Generated by Cloudflare Forge and Fern; pinned versions and the source contract hash are in [generation.json](generation.json).
